# Zeal Institute Alumni Network App

A modern and luxurious web application for Zeal Institute alumni to connect, share resources with current students, and facilitate mentorship and networking.

## Features

- **User Authentication**: Register and login system for alumni with client-side storage
- **Resource Sharing**: Share placement tips, interview experiences, and other resources with current students
- **Mentorship Requests**: Accept and manage mentorship requests from students
- **Event Management**: View upcoming events and RSVP to attend
- **Responsive Design**: Fully responsive UI that works on both desktop and mobile devices

## Technologies Used

- **HTML5**: For the structure of the web pages
- **CSS3**: For styling with modern features like Flexbox, Grid, and CSS variables
- **JavaScript**: For client-side functionality and interactions
- **LocalStorage**: For data persistence in the browser

## Getting Started

1. Clone this repository or download the files
2. Open `index.html` in a modern web browser
3. Navigate through the site to explore its features
4. Register a new account to access the dashboard

## Pages

- **Home**: Landing page with key information and upcoming events
- **Register**: Sign up page for new alumni
- **Login**: Authentication page for existing users
- **Dashboard**: Main interface for logged-in users with the following sections:
  - **Overview**: Quick stats and recent activities
  - **Resources**: Share and view resources
  - **Mentorship**: Manage mentorship requests
  - **Events**: View and RSVP to upcoming events
  - **Settings**: Update profile information and change password

## Usage Instructions

### Registration
1. Click "Register" in the navigation menu
2. Fill in your details (name, email, password, graduation year, department, expertise)
3. Submit the form to create your account

### Login
1. Click "Login" in the navigation menu
2. Enter your email and password
3. Click "Login" to access your dashboard

### Sharing Resources
1. Navigate to the "Resources" section in your dashboard
2. Fill in the resource details (title, type, content)
3. Click "Share Resource" to publish

### Managing Mentorship Requests
1. Navigate to the "Mentorship" section in your dashboard
2. View pending requests and accept or decline them
3. View your current mentees

### RSVPing to Events
1. Navigate to the "Events" section in your dashboard
2. Browse upcoming events
3. Click "RSVP" for events you wish to attend

## Notes

- This is a client-side only application that uses LocalStorage for data persistence
- In a production environment, a proper backend with secure authentication would be implemented
- The application includes demo data for mentorship requests and events
